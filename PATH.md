# «Путь» — ведущий по продукту GOOD Growth

> Один экран — один вопрос. Но человеку нужен **компас**: где я сейчас и что дальше.
> «Путь» отвечает на этот вопрос, не мешая работать.

---

## 1. Где он виден

| Где | Что | Когда |
|---|---|---|
| **«Стол»** (`/app`) | **Лента со светом** — большая, подробная | только на Столе |
| **Левая панель** | **Тропа** — пять точек, компактно | **на всех страницах** |

Лента — карта. Тропа — компас. Тропа всегда перед глазами, лента — когда человек думает «что вообще происходит».

**Почему лента не на всех страницах:** на странице цели она отодвигает главное — поле ввода. Один экран должен задавать **один** вопрос.

---

## 2. Пять шагов и их цвета

```
01  Цель      #F8961D  оранжевый   одна фраза о деле
02  Разбор    #E0574B  коралл      кому и о чём говорить
03  Ритм      #A96AB8  фиалка      сколько раз в неделю
04  Посты     #28A992  бирюза      готовые тексты и картинки
05  Отклик    #4CB853  зелёный     что сработало, а что нет
```

Порядок цветов не случайный: **от тепла к жизни**. Пятый — зелёный: путь заканчивается ростом, а не отчётом.

**Цвет = номер шага.** Он не меняется от прогресса. Прогресс показывают **заливка, галочка и свечение**, а не цвет.

---

## 3. Откуда берутся состояния

Только **живые данные**. Ручных галочек нет — система не врёт о прогрессе.

| Шаг | Считается сделанным, если | Источник |
|---|---|---|
| **Цель** | есть хотя бы одна цель | `/api/analytics` → `totals.goals` |
| **Разбор** | у свежей цели есть стратегия (summary / темы / аудитория) | `/api/goals` → `/api/goals/:id` |
| **Ритм** | сохранена сетка слотов | `/api/slots` → `slots[]` |
| **Посты** | создан хотя бы один пост | `/api/analytics` → `totals.posts` |
| **Отклик** | есть хотя бы один опубликованный пост | `/api/analytics` → `totals.published` |

**Ничего не запирается.** Все инструменты доступны при `0 из 5`. Путь показывает, а не разрешает.

---

## 4. Что значит «сейчас»

**Сейчас = первый несделанный шаг.** Всё, что до него — пройдено. Всё, что после — впереди.

### Особый случай: пробел

Бывает, что шаг позади — не закрыт, а более поздний — уже сделан.
Пример: ритм не задан, но посты уже есть (61 пост без времени — наша реальная история).

Тогда:

```
счётчик:  «3 из 5 · не хватает: ритм»
шаг 03:   «· сейчас»
шаг 04:   «· сделано · уже есть»
```

**Не прячем и не переписываем.** Показываем ровно то, что есть, и называем затор своим именем. Это и есть «правда вместо имитации».

---

## 5. Правила — четыре

```
1. Ничего не заперто: любой шаг можно делать в любом порядке.
2. Ничего не сгорает: не сделал сегодня — дождётся.
3. Ничего не краснеет: 0 из 5 — не приговор, а «с чего начать».
4. Ничего не врёт: состояния только из данных, без ручных отметок.
```

**Красный в пути не используется.** Красный — для ошибок («картинка не получилась»). В дороге не должно быть тревоги.

---

## 6. Чего в пути нет

**Шестого шага «Публикация» нет.** Публикация — это результат шага «Посты», а не отдельная станция. Иначе путь начнёт считать одно и то же дважды.

**«Первые шаги» внутри разбора — это другое.** Там **задачи** («оформить шапку», «позвать первых»). Здесь — **дорога по продукту**. Две разные вещи, и они не дублируют друг друга.

## 8. Как это связано с остальным продуктом

```
Цель ──→ Разбор ──→ Ритм ──→ Посты ──→ Отклик
  │         │          │         │          │
  │      strategy_json │   post + image   published_at
  │                    │         │
  └── то же, что в «Публикациях»: сетка слотов
```

Путь **не** отдельная база и не отдельный экран. Он читает то, что продукт уже знает, и показывает одним взглядом.

**Когда появится видео** — оно станет частью шага «Посты» (кнопки и этапы уже готовы), а не шестым шагом.

# Четыре идеи из Arsminal — что берём в GOOD

> Arsminal посмотрели 22 ноября 2026, разобрали и удалили.
> Он — мультиплексор терминалов вокруг чужих CLI-агентов (claude, codex), закрытый код.
> Как продукт не нужен. Но четыре вещи из него действительно хороши.

## 1. Телефон-пульт

**Что это у него:** в приложении есть QR-код, телефон открывает веб-страницу и управляет
терминалом на компьютере (WebSocket-сессия).

**Что делаем у нас:** клиент открывает `growth.go-ood.com/p/<код>` с телефона и видит
свои посты: что выходит сегодня, что запланировано, кнопка «опубликовать сейчас».
Без приложения — просто ссылка.

**Зачем:** владельцу маленького дела некогда садиться за компьютер. Телефон — его пульт.

**Сложность:** средняя. Нужна одноразовая ссылка (токен), узкий экран, те же API.

## 2. Голосовой ввод цели

**Что это у него:** микрофон в чате, речь превращается в текст.

**Что делаем у нас:** в поле «Твоя цель» кнопка микрофона: наговорил — текст появился.
Дальше обычный разбор.

**Зачем:** сформулировать цель вслух легче, чем печатать. Особенно с телефона.

**Сложность:** низкая-средняя (Web Speech API в браузере, без серверных затрат).

## 3. Память проекта (бренда)

**Что это у него:** у каждого чата есть «Память проекта» — заметки, которые агент
всегда учитывает.

**Что делаем у нас:** у каждого бренда — поле «Что важно знать»: тон голоса, чего
не говорим, имена, факты. Эти заметки попадают в каждый разбор и каждый пост.

**Зачем:** сейчас бренд — только имя. Память проекта делает разборы точнее с каждым разом.

**Сложность:** низкая (таблица + вставка в промпт).

## 4. Переключатель «спрашивать / делать сам»

**Что это у него:** режим агента: «спрашивает разрешение перед каждым действием»
или «делает всё без подтверждений».

**Что делаем у нас:** переключатель для публикаций: «спрашивать перед каждым постом»
или «публиковать по расписанию без вопросов». По умолчанию — спрашивать.

**Зачем:** контроль без лишних кликов; у нас уже есть approvals, нужен понятный вид.

**Сложность:** низкая (UI + флаг у бренда).

---

## Порядок работы

1. **Память бренда** — быстрее всего и сразу улучшает качество
2. **Голосовой ввод** — просто и заметно для человека
3. **Переключатель публикаций** — контроль
4. **Телефон-пульт** — самый крупный, делать после открытия продаж

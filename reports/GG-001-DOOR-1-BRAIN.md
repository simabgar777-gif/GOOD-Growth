# GG-001 · Дверь 1 «Мозг» — постройка и ходовые

_Архивный отчёт верфи GOOD Growth · 28 сентября 2026 · Боцман_

## Задача (приказ от Боцмана 1, ГО Капитана)

Простой локальный прототип: человек вводит цель → система разбирает её на стратегию
(аудитория, темы, ритм, каналы) и показывает на экране. Без соцсетей, без публикаций.
Стек: Node.js, SQLite, тёмный GOOD-стиль с золотым светом. Критерий: Капитан открывает
сайт, вводит цель, видит разбор — без ошибок.

## Что построено

```
E:\GOOD-Growth\
├── server.js               HTTP-сервер + интеграция DeepSeek + демо-мозг
├── db.js                   SQLite (node:sqlite, встроена в Node 22+)
├── public\index.html       Экран: герой, форма цели, разбор, журнал
├── public\app.js           Логика экрана (fetch, рендер, состояния)
├── data\goodgrowth.db      Локальная база (цели + настройки)
├── .env / .env.example     Ключ DeepSeek (DEEPSEEK_API_KEY), порт
├── start-good-growth.bat   Запуск двойным щелчком
├── reports\                Этот отчёт + CURRENT-REPORT.md
└── README.md               Инструкция для Капитана
```

Ключевые решения:

- **Ноль npm-зависимостей.** Node 22 даёт http, fetch и SQLite из коробки — на слабом ПК
  установка мгновенная, обслуживать нечего. PostgreSQL не нужен вплоть до Двери 4.
- **Демо-режим из коробки.** Без ключа система не падает, а честно собирает разбор локально
  (профили: юрдом / продажи / обучение / общий) и помечает его как демо. Переключение —
  ссылка в подвале экрана; с ключом в `.env` сервер сам переходит в живой режим.
- **Нормализация ответа разума.** Что бы ни ответил DeepSeek, `normalizeStrategy()` приводит
  разбор к безопасной схеме (аудитория / темы / ритм / каналы / шаги / резюме) — экран не сломается.
- **Доступность:** label у поля, aria-describedby, role=alert на ошибку, aria-live на статус,
  focus-visible на всех интерактивных, контраст тёплой палитры выдержан.

## Инцидент сборки (для истории верфи)

Первая сборка шла через PowerShell-скрипты: PS 5.1 прочёл UTF-8-файлы как CP1251, и все
русские тексты легли кракозябрами — и в файлах, и в самом сборщике. Лечение: файлы с
русским текстом пишутся напрямую как UTF-8, а ASCII-скрипт только копирует их на верфь.
Урок записан: «PowerShell 5.1 + UTF-8 без BOM = кракозябры; сборку делать через node-скрипт».

# Ритуал работы с Git (верфь GOOD Growth)

## Перед началом работы (на любом компьютере)
    git pull

## После содержательной задачи
    git add .
    git commit -m "что сделано — кратко"
    git push

## Железные правила
1. .env НИКОГДА не попадает в GitHub — там ключи (DeepSeek, Pollinations, Telegram).
2. data/*.db не коммитим — база живёт локально на каждом компьютере.
3. public/generated/ не коммитим — картинки можно перегенерировать.
4. Репозиторий приватный. Новых участников добавляет только Капитан.
5. Если ключ утёк — немедленно отозвать на сайте сервиса и заменить в .env.

## Запуск на новом компьютере
1. Установить Node.js 22+
2. git clone <репозиторий>
3. Скопировать .env.example -> .env, вставить свои ключи
4. start-good-growth.bat -> http://localhost:3000

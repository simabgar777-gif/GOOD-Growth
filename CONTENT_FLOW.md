# Создать контент — главная процедура

Капитан, 03.11: «создать контент — это самое важное в нашем сайте.
Не хочу спешить. У нас уже есть вариант Buffer — наш вариант по структуре
и функционалу. Поищи, посмотри, прикинь».

Ниже — что изучил, три варианта структуры и рекомендация.

---

## Что делает Buffer (наш ориентир)

1. **Ряд каналов сверху.** Иконки сетей, отмечаешь несколько — пост уйдёт во все.
2. **Поля под каждый канал.** Появляются отдельные поля «Чем бы вы хотели
   поделиться?» — основной текст подставляется, но правится отдельно.
3. **Счётчик под конкретную сеть** (280 у X, 2200 у Instagram).
4. **Показ справа** — живая лента выбранной сети с лайками и комментариями.
5. **Пустой показ**, пока канал не выбран: «Предварительный просмотр
   вашего сообщения доступен здесь» — не ложная лента.
6. **Вложения**: перетащить файл или выбрать, «Первый комментарий».
7. **Внизу**: «Сохранить черновик» слева, «Расписание» справа.

## Что делает Metricool

- Выбрал сети → кнопка **«Edit by network»**: один шаблон, а текст
  правится **по сети отдельно** (вкладки). Это ближе к нам: не дублировать пост,
  а дать **шаблон + правку под каждую сеть**.
- Форматы и лимиты у каждой сети свои — гайд «scheduling and posting
  options by social network».

## Наш канон, который нельзя ломать

- Человек, а не «пользователь».
- Ничего не выдумывать: не подключено — так и пишем «скоро».
- Цвет только там, где несёт смысл. Красный — ошибка.
- Никаких процентов, рейтингов, «15/100 готовности».
- Пустота — тоже сообщение. Не заполнять экран ради плотности.

## Вариант A — «Один холст, много сетей» (Buffer)

```
┌ Создать контент ─────────────────────────────────────────┐
│ [✈] [VK] [IG] [f] [in]  ← отметить сети                  │
├───────────────────────────────┬───────────────────────────┤
│ Чем поделимся?                │  TELEGRAM                 │
│ [ большой текст ]             │  ┌─────────────────────┐  │
│                               │  │ ◈ канал             │  │
│ [+ картинка] [первый коммент] │  │ текст поста         │  │
│                               │  │ 👁 0                 │  │
│ Вкладки: [TG] [VK] [IG]       │  └─────────────────────┘  │
│ [текст под IG отдельно]       │  16:9 · 435 / 4096 знаков │
├───────────────────────────────┴───────────────────────────┤
│ Сохранить черновик      [сейчас ▾]        [В очередь]     │
└───────────────────────────────────────────────────────────┘
```

**Плюс:** как у Buffer, привычно, всё на одном экране.
**Минус:** на телефоне вкладки жмутся; много текста — много скролла.

## Вариант B — «Мастер: 4 шага»

1. **Куда** — отметить сети.
2. **Что** — текст, картинка.
3. **Как** — правка под каждую сеть + показ.
4. **Когда** — сейчас / в слот ритма / своё время.

**Плюс:** очень понятно новичку, ничего не забыть.
**Минус:** медленнее для того, кто делает это каждый день.
Мастер уже есть в тропе — внутри шага он будет мастером в мастере.

## Вариант C — «Очередь + лента»

Слева очередь постов, справа лента, снизу «Новый пост».
Как Buffer Publish → Queue.

**Плюс:** хорошо, когда постов много.
**Минус:** слабо для **одного** поста; нашему человеку важнее сделать
один пост хорошо, а не управлять очередью из 50.

## Рекомендация: **A, но с одной правкой из B**

**Основа — A** (один холст, сети сверху, показ справа).
**Из B берём только одно:** сети выбираются **первым действием**,
до текста — потому что от выбора сети зависит размер картинки и лимит.

Порядок на экране:

1. **Сети** — ряд иконок с честными статусами («подключён» / «скоро»).
2. **Текст** — один основной.
3. **Вкладки сетей** — появляются только если сетей больше одной;
   в каждой поле с подставленным основным текстом и счётчиком под лимит.
4. **Картинка** — одна, но рамка показа меняется под сеть (16:9 / 1:1 / 1.91:1).
5. **Показ справа** — живая лента; пока сеть не выбрана — тихая заглушка.
6. **Когда** — сейчас / в ближайший слот ритма / своё время.
7. **Внизу** — «Сохранить черновик» слева, «В очередь» справа.

### Что не берём у Buffer

- Их «AI-помощник» рядом с текстом — у нас разбор и так пишет текст.
- «Create another» — у нас есть счётчик 1/3/5/10, этого достаточно.
- Календарь/список — это отдельная страница «Публикации».

## План на завтра (по шагам, каждый — проверяемый)

| # | Что | Проверка |
|---|---|---|
| 1 | Ряд сетей в редакторе, мультивыбор, статусы | отметил 3 — видно 3 |
| 2 | Вкладки текста под каждую выбранную сеть | правка в IG не меняет TG |
| 3 | Счётчик и рамка картинки под активную сеть | 280/2200/4096 меняются |
| 4 | Честная заглушка показа, пока сеть не выбрана | без ложной ленты |
| 5 | «Когда»: сейчас / слот ритма / своё время | запись в /schedule |
| 6 | Сохранить черновик / В очередь | PATCH и POST работают |
| 7 | Телефон: сети в строку, вкладки в скролл | без горизонтального скролла |

**Чего не делаем завтра:** реальные подключения сетей (только Telegram),
видео, загрузка своей картинки с диска (пока рисуем сами).
